# MineSense Atlas

矿运感知建筑综合实验平台 · 官方展示与 Windows x64 软件发行

本仓库提供官网展示页面、软件安装包、安装说明和文件校验值。软件采用本机服务与浏览器界面：安装后从开始菜单启动，在当前电脑的浏览器中使用。

[访问 MineSense Atlas 官网](https://wxy11117.github.io/MineSense-Atlas-Public/)

## 下载

[下载最新 Windows 安装包](https://github.com/wxy11117/MineSense-Atlas-Public/releases/latest)

支持 Windows 10 / 11 x64，内置 Python 运行时，按当前 Windows 用户安装。当前版本未进行代码签名。

## 开始使用

1. 在 Releases 下载安装程序及 `SHA256SUMS.txt`，核对文件校验值后安装。
2. 从开始菜单打开 **MineSense Atlas**，浏览器会打开本机工作台。
3. 首次使用自行创建本机账号和密码。
4. 按需连接自己的摄像头、配置外部设备及兼容数据目录。

没有数据时，软件显示空状态或明确标识的布局预设。安装包不附带用户账号、采集录像、点云记录、标定记录、复核结果、研究数据集或模型权重。

## 工作台

- 车辆空间与车体坐标预设。
- 雷达点云查看、定向测距及回放界面。
- 电脑和 USB 摄像头预览、可选 YOLOv8m 推理入口。
- 设备状态、标定状态及人工复核。

实时推理需要另行配置兼容的推理环境和官方模型；雷达实时数据需要外部采集服务及相应设备。界面预设不代表已经实现实车自动驾驶或取得定位精度验证。

## 本机运行

服务仅监听本机回环地址。关闭浏览器后，如需结束服务，请使用开始菜单的 **Stop MineSense Atlas**。软件运行数据与安装目录分开保存，升级及卸载保留用户数据。

详见 [安装与使用](INSTALLATION.md) 和 [发行说明](RELEASE-NOTES.md)。本仓库不托管在线实验工作台。
